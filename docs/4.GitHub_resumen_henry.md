# GitHub: Todo lo que necesitas saber (Resumen Guía Soy Henry)

## 1. Fundamentos: GitHub, Git y Seguridad

* **¿Qué es GitHub?:** Es una plataforma colaborativa basada en la nube (funciona de manera similar a una red social para desarrolladores) donde se alojan millones de proyectos de software, muchos de ellos de código abierto (*open-source*).
* **Relación con Git:** GitHub utiliza el sistema de control de versiones **Git**. Mientras que Git te permite trabajar de forma local (incluso *offline*) clonando repositorios y registrando cambios en tu computadora, GitHub actúa como el repositorio remoto en línea para almacenar el código, sincronizar versiones y colaborar con equipos de todo el mundo.
* **Seguridad en la plataforma:** Protege tu código y tus datos mediante tres capas principales:
  * **Autenticación de dos factores (2FA)** para resguardar el acceso a las cuentas.
  * **Escaneo automático de vulnerabilidades** para alertar fallos en el código.
  * **Cifrado de datos** tanto en tránsito como en reposo.

## 2. Cómo optimizar tu perfil para reclutadores (*Recruiters* y *Tech Leads*)

Las empresas evalúan tu cuenta de GitHub como un portafolio técnico real. Para destacar, debes optimizar cuatro elementos clave:

* **README de perfil (Carta de presentación):** Crea un repositorio público con el mismo nombre exacto de tu usuario (`github.com/usuario/usuario`) y añade un archivo `README.md`. Allí debes incluir tu presentación personal, las tecnologías que dominas, puntos de contacto, redes profesionales y tu propuesta de valor.
* **README en cada proyecto:** Cada repositorio debe tener su propio archivo `README` explicando claramente el objetivo del proyecto, las herramientas o lenguajes utilizados y una visión general de su funcionamiento.
* **Repositorios destacados (*Pins*):** Fija entre **3 y 4 proyectos** principales en la portada de tu perfil y mantenlos actualizados conforme sumas mejores trabajos.
* **Gráfico de contribuciones (los "cuadraditos verdes"):** Refleja tu constancia diaria mediante *commits* (confirmaciones de cambios), *pull requests* (solicitudes de extracción/revisión) e *issues* (propuestas o reportes). Cuanto más oscuro es el verde, mayor actividad hubo ese día. Además, conviene activar la opción *Private Contributions & Activity Overview* en *Contribution Settings* para que también se contabilicen tus aportes en repositorios privados.

## 3. Cómo crear y publicar un portafolio web robusto con GitHub Pages

Para llevar tu perfil un paso más allá y alojar una página web gratuita con tu portafolio, sigue estos 5 pasos:

1. **Setea tu repositorio de GitHub:**
   * Inicia sesión en [GitHub](https://github.com/) y crea un repositorio nuevo.
   * Nómbralo exactamente `username.github.io`.
   * Configúralo como **Público** y, si deseas, agrega un `README` inicial.
2. **Diseña tu portafolio:**
   * Define un diseño que refleje tus habilidades y marca personal.
   * Personaliza los archivos con tu nombre, habilidades, proyectos y contacto.
   * Ajusta los estilos CSS (colores, fuentes y distribución) según tu identidad visual.
3. **Agrega tu contenido al repositorio:**
   * Llena el portafolio con tus proyectos, habilidades, CV y experiencia.
   * Coloca los archivos HTML, CSS, imágenes y scripts en la carpeta del repositorio.
   * Si usas un tema de [Jekyll](https://jekyllrb.com/), configura el archivo `_config.yml`.
   * Ejecuta `commit` y `push` hacia GitHub.
4. **Despliega (*deploy*) tu sitio:**
   * Activa **GitHub Pages** en la configuración (*Settings*) del repositorio.
   * Selecciona la rama de despliegue (generalmente `main` o `master`).
   * Verifica que tu web esté en línea en `https://username.github.io`.
   * Si surge algún problema, revisa la pestaña **Actions** para detectar errores.
5. **Mantén tu sitio actualizado:**
   * Actualiza tus proyectos y tu CV con regularidad y revisa que el sitio funcione bien.
   * Si tienes un dominio propio, configúralo.
   * Monitorea el tráfico con [Google Analytics](https://analytics.google.com/) y optimiza el SEO con *meta tags* y palabras clave.
   * Muestra tu perfil de GitHub junto con tus [GitHub Gists](https://gist.github.com/).
